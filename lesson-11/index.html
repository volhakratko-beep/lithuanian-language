Грамматика

1. Условное (сослагательное) наклонение: вежливая просьба

Norėčiau nuplauti automobilį. Ar galėtumėte atvažiuoti dabar?

Основа инфинитива (без -ti) + окончания. Так формируются вежливые просьбы: «я хотел бы», «не могли бы вы».

ЛицоОкончаниеnorėtigalėti
aš-čiaunorėčiaugalėčiau
tu-tum(ei)norėtumgalėtum
jis, ji, jie, jos-tųnorėtųgalėtų
mes-tu(mė)menorėtume / norėtumėmegalėtume / galėtumėme
jūs-tu(mė)tenorėtumėtegalėtumėte
Для «вы» (jūs) используйте norėtumėte / galėtumėte — это самая вежливая форма: Ar galėtumėte suremontuoti mašiną?

2. Po + родительный падеж: «через …, после …»

Po darbo važiuoju į plovyklą. Mašiną pataisysime po valandos.

Им. п. ед. ч.Род. п.Пример
-as-odarbas → po darbo
-is-iosavaitgalis → po savaitgalio
-a-osvalanda → po valandos
-ė-ėssavaitė → po savaitės
mėnuomėnesiopo mėnesio

Множественное число: -a → -ų (valandos → valandų), -ė → -ių (minutės → minučių, savaitės → savaičių).

  • Būsiu po dešimt minučių.
  • Atvažiuokite po dviejų savaičių.
  • Mašiną pataisysime po trijų valandų.

3. Женские числительные в родительном падеже

Им. п.Род. п.

10, 11 …dešimt, vienuolikos, penkiolikos; dvidešimt
После 10 и более часто остаётся форма dešimt (po dešimt minučių), а для 11–19 — родительный на -os (po penkiolikos minučių).

4. Дательный падеж: на какой срок (kuriam laikui?)

Norėčiau išsinuomoti mašiną parai. Kokia nuomos kaina valandai / dienai / savaitei / mėnesiui?

Им. п. ед. ч.Дат. п.Пример
-a-aipara → parai; diena → dienai; valanda → valandai
-ė-eisavaitė → savaitei
mėnuo-iuimėnuo → mėnesiui

Множественное число: -a → -oms, -ė → -ėms: dienos → dienoms, savaitės → savaitėms.
